① 写入通道（只需设置一次）

账号表存放在仓库的 accounts.json，保存时需要用你的 GitHub 令牌提交一次。令牌只保存在这台电脑的浏览器里，不会上传到任何服务器。

生成地址：github.com/settings/personal-access-tokens/new → 仅选择 amv-site 仓库 → Repository permissions 里把 Contents 设为 Read and write。

② 开通一个新账号

只有在这里开通过的人，才能登录站点。密码只以哈希形式保存，你自己也看不到明文。

生成后要点下面的「保存到云端」才真正生效

③ 账号列表

修改或删除后同样需要「保存到云端」。改动会让对方当前的登录状态失效（下次刷新即掉线）。
